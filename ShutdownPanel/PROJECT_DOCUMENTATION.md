## 🎯 نظرة عامة على المشروع

**Shutdown Panel** هو نظام متكامل من فئة **Desktop Utilities** موجه لنظام تشغيل ويندوز، يجمع بين:
1. **لوحة تحكم محلية احترافية (Local Panel):** مبنية بتصميم الزجاجي المعتم (Glassmorphism) والوضع الداكن، تدعم اللغة العربية والإنجليزية وتعمل بتقنية Edge WebView2 لتوفير أداء خفيف وجمالية رسومية فائقة.
2. **ويدجت ساعة سطح المكتب (Edge Clock Widget):** شريط أنيق يلتصق بحافة الشاشة يعرض الوقت الحقيقي، التاريخ، وحالة العداد التنازلي مع دعم 4 أنماط بصرية وتكبير الخط الرقمي (DS-Digital) ليلامس حواف الإطار بسلاسة.
3. **نافذة العد التنازلي التفاعلية (Countdown Overlay):** تطفو في أعلى الشاشة لعرض الوقت المتبقي لأي إجراء مجدول مع إمكانية الإلغاء السريع بنقرة واحدة.
4. **خادم تحكم عن بعد متطور (LAN Remote Server):** يتيح إدارة الحاسوب بالكامل من أي متصفح هاتف ذكي عبر تطبيق ويب تقدمي (PWA) دون الحاجة لتثبيت أي تطبيق على الهاتف.
5. **عميل سطح مكتب للشبكة (Desktop Client):** يتيح لمستخدمي الشبكة المحلية اكتشاف أجهزة الحاسوب المشغلة للخادم تلقائياً وإدارتها عن بعد.

## 🏗️ المعمارية وتدفق البيانات (Architecture & Data Flow)

يعتمد النظام على نمط **Hybrid Desktop Application**، حيث يتم الفصل الكامل بين منطق النظام في بايثون وطبقة العرض المكتوبة بتقنيات الويب الحديثة.

```mermaid
flowchart TD
    subgraph Core Engine [Python Core Engine]
        CMD[Commander]
        SCH[Scheduler & Schedules]
        MET[Hardware Metrics]
        INP[Input Controller]
        SCR[Screen Streamer]
        SET[Settings Manager]
        LOG[App Logger]
        SRV[LAN Remote Server]
    end

    subgraph Native Desktop Shell [PyWebView / WebView2 Windows]
        MW[Main Window: index.html]
        WW[Edge Clock Widget: widget.html]
        CW[Countdown Window: countdown_overlay.html]
        TRY[System Tray Icon: pystray]
    end

    subgraph Remote Clients [Remote Control Layers]
        MOB[Mobile Phone PWA: mobile.html]
        CLT[Desktop Client: client_main.py]
    end

    MW <==>|JS API Bridge: api.py| Core Engine
    WW <==>|JS API Bridge: api.py| Core Engine
    CW <==>|JS API Bridge: api.py| Core Engine
    TRY <==> Core Engine

    SRV <==>|HTTPS / WebSocket / MJPEG| MOB
    SRV <==>|UDP Discovery & REST API| CLT
```

### آلية عمل نوافذ العرض الثلاثة:
1. **النافذة الرئيسية (`MainWindow`):** تُفتح لإعداد المؤقت، الجدولة، ضبط الخادم، فحص العتاد، أو استعراض السجلات، وعند النقر على زر الإغلاق تُخفى تلقائياً إلى شريط المهام (Tray) دون إيقاف الخدمات.
2. **ويدجت الحافة (`Edge Clock Widget`):** نافذة صغيرة لا تحتوي على إطارات (Frameless) تستقر على الحافة اليمنى للشاشة بنمط Always-on-Top مع تفعيل خاصية `WS_EX_TOOLWINDOW` عبر Windows API حتى لا تظهر في شريط المهام أو قائمة `Alt+Tab`.
3. **نافذة العد التنازلي (`Countdown Overlay`):** نافذة منبثقة أعلى منتصف الشاشة تظهر تلقائياً بمجرد بدء عداد تنازلي، وتختفي فور انتهائه أو إلغائه.

## 🧩 التفاصيل البرمجية للوحدات الأساسية

### 1. وحدة الأوامر (`core/commander.py`):
- تخطيط الأوامر بصيغة خطة موحدة (`Plan` Dictionary).
- دعم الإجراءات:
  - إيقاف التشغيل الفوري أو المؤقت (`shutdown /s /t ...`).
  - إعادة التشغيل (`shutdown /r /t ...`).
  - الإسبات (`shutdown /h`).
  - السكون (`rundll32.exe powrprof.dll,SetSuspendState 0,1,0`).
  - قفل الشاشة (`rundll32.exe user32.dll,LockWorkStation`).
  - تسجيل الخروج (`shutdown /l`).
  - إيقاف أجهزة الشبكة البعيدة (`shutdown /m \\computer /s`).
- التحقق الصارم من كود الخروج `ExitCode == 0` لضمان نجاح التنفيذ الفعلي مع التقاط أسباب الفشل بلغة المستخدم.

### 2. محرك العد التنازلي والجدولة (`core/scheduler.py` & `core/schedules.py`):
- **المؤقت عالي الدقة:** يعتمد على `time.monotonic()` لحساب زمن الموت المحدد (Deadline) لتفادي أخطاء تغير توقيت النظام أو فارق التوقيت الصيفي.
- يعمل المؤقت داخل خيط معزول (`threading.Thread`) مع بث حالة دورية (Tick Event) كل ثانية تشمل الوقت المتبقي، النسبة المئوية، والإجراء المجدول.
- إمكانية الإيقاف المؤقت (Pause)، الاستئناف (Resume)، والتعديل الديناميكي للوقت أثناء الجريان.
- **الجدولة الأسبوعية:** دعم تعيين مهام تتكرر أسبوعياً في أيام محددة (مثل: إيقاف التشغيل من الأحد إلى الخميس الساعة 23:30).

### 3. مستشعر العتاد والبطارية (`core/metrics.py`):
- مراقبة نسبة استخدام المعالج `psutil.cpu_percent` مع حماية من تجميد الخيط.
- قياس استهلاك الذاكرة العشوائية RAM، مساحة الأقراص المتاحة (C و D وغيرها).
- قراءة حالة البطارية (نسبة الشحن، موصول بالشاحن أم لا).
- استخراج درجات حرارة المكونات عبر Windows WMI / ACPI Thermal Zone إن كانت مدعومة باللوحة الأم.

### 4. محاكي المدخلات ومستوى الصوت (`core/input_controller.py`):
- محاكاة حركة مؤشر الفأرة المطلقة والنسبية عبر `ctypes.windll.user32.SendInput`.
- دعم النقر الأيمن، الأيسر، المزدوج، وعجلة التمرير (Scroll Wheel).
- دعم لوحة المفاتيح الافتراضية مع المعالجة الكاملة للحروف العربية والإنجليزية والرموز الخاصة عبر إرسال أكواد Unicode المباشرة (`KEYEVENTF_UNICODE`).
- دعم أزرار الوسائط المتعددة (تشغيل/إيقاف، المسار التالي، المسار السابق).
- التحكم الدقيق بمستوى صوت ويندوز الرئيسي عبر بروتوكول `IAudioEndpointVolume` (COM Interface) دون الحاجة لمحاكاة ضغطات أزرار الصوت المتتالية.

### 5. بث الشاشة الحي (`core/screen_streamer.py`):
- التقاط الشاشة بمعدل إطارات مرتفع وزمن تأخير شبه منعدم باستخدام مكتبة `MSS`.
- ضغط الإطارات بدقة قابلة للتعديل بصيغة JPEG ونقلها عبر تدفق Multipart MJPEG Stream.
- دعم خيار بديل تلقائي باستخدام `Pillow.ImageGrab` في حال عدم توفر مكتبة MSS.

## 🎨 واجهات المستخدم وتجربة الاستخدام (UI/UX)

### الفلسفة التصميمية:
تتبع جميع واجهات ARN Technology معايير التصميم الحديثة:
- **الوضع الداكن الفاخر (Deep Dark Theme):** الاعتماد على درجات الرمادي الداكن والأزرق الليلي (`#070c16` إلى `#0d1f38`) لإراحة العين.
- **تأثير الزجاج المصنفر (Glassmorphism):** استخدام `backdrop-filter: blur(14px)` وحدود متوهجة خفيفة (`rgba(34, 211, 238, 0.4)`).
- **الخطوط المجهزة محلياً:**
  - **خط DS-Digital:** خط رقمي سُباعي مخصص لعرض الوقت في ويدجت الساعة وشاشة العد التنازلي بدقة عالية وأرقام متوهجة.
  - **خط Cairo:** الخط المعتمد لنصوص الواجهة العربية لعرض نقي ومتناسق.
  - **خط Outfit:** الخط المعتمد للأرقام الإنجليزية والمصطلحات التقنية.
- **أنماط ويدجت الساعة الجانبي:**
  1. **نمط Cyber (الافتراضي):** واجهة رقمية عريضة متوهجة بأرقام عملاقة تملأ الشاشة.
  2. **نمط Pill (الكبسولة الزجاجية):** تصميم نحيف ودائري يقسم الوقت والبيانات بفاصل عمودي ناعم.
  3. **نمط HUD (الأسلوب التكتيكي):** مظهر مستقبلي مستوحى من واجهات الخيال العلمي وقص أطراف زاوية 45 درجة وشريط تتبع للثواني.
  4. **نمط Luxury (النمط الذهبي):** خلفية دائرية ناعمة مع لمسات ذهبية ملكية وأرقام مريحة.
  5. **الساعة التناظرية المصغرة (Analog Clock):** عند تصغير الويدجت للنقر الجانبي، يتحول إلى قرص ساعة عقارب كلاسيكية ثلاثية الأبعاد مرسومة بـ HTML5 Canvas.

## 🌐 نظام التحكم عن بعد وخادم الشبكة المحلية (Remote Server & PWA)

يحتوي النظام على خادم ويب مدمج فائق الخفة مبني على `http.server` المعياري مع تحسينات أداء متعددة الخيوط (`ThreadingHTTPServer`):

### ميزات الخادم:
- **تطبيق PWA متكامل (`mobile.html`):** بمجرد فتح عنوان الخادم على متصفح الجوال (Chrome / Safari)، يمكن للمستخدم تثبيته كأيقونة تطبيق رسمي على شاشته الرئيسية.
- **التحكم باللمس (Touchpad):** تحويل شاشة الهاتف إلى فأرة حاسوب تدعم النقر بإصبع، النقر المزدوج، التمرير بإصبعين، والنقر الأيمن.
- **مدير الملفات المتكامل (LAN File Manager):**
  - تصفح محركات الأقراص والمجلدات.
  - رفع الملفات مع شريط تقدم مباشر وحظر الملفات الخطرة أو محاولات تخطي المسار (`Path Traversal Protection`).
  - تنزيل الملفات أو ضغط المجلدات كاملة وتنزيلها كملف `.zip`.
  - حذف الملفات بأمان بنقلها إلى **سلة المحذوفات (Recycle Bin)** عبر مكتبة `send2trash` لتجنب الحذف النهائي غير المقصود.
- **مدير العمليات والمهام (Task Manager):** استعراض قائمة العمليات الحالية مع ترتيبها حسب استهلاك المعالج والذاكرة وإمكانية إنهاء أي تطبيق بنقرة واحدة.
- **أداة Wake-on-LAN:** لإرسال حزمة الماجيك وإيقاظ أجهزة الكمبيوتر الأخرى على الشبكة المحلية.

## 💻 عميل سطح المكتب والاكتشاف التلقائي

بالإضافة لتطبيق الجوال، يوفر المشروع تطبيقاً منفصلاً لسطح المكتب **Shutdown Panel Client**:
- مخصص لتثبيته على أجهزة الكمبيوتر المحمولة أو المكتبية الأخرى على نفس الشبكة.
- **بروتوكول الاكتشاف التلقائي (UDP Discovery Protocol):**
  - يقوم الخادم الرئيسي ببث نبضات دورية عبر بروتوكول UDP على المنفذ `42125` تحتوي على اسم الجهاز، المنفذ، وحالة التشفير.
  - يقوم العميل بفتح مأخذ استماع (UDP Listener) ليكتشف الخوادم المتاحة تلقائياً في ثوانٍ معدودة دون الحاجة لمعرفة عنوان الـ IP يدوياً.

## 🔒 منظومة الأمان والخصوصية

تم تصميم النظام بمعايير أمان صارمة تناسب منح التحكم الكامل بجهاز الحاسوب:
1. **المصادقة عبر رمز التوكن (Token Authentication):**
   - يتم توليد رمز عشوائي سري بطول 32 بايت من حروف مشفرة (`secrets.token_urlsafe`).
   - لا يمكن الوصول لأي نقطة نهاية (API Endpoint) أو حتى استعراض رمز QR دون تقديم التوكن الصحيح.
2. **تشفير الاتصال (HTTPS / TLS):**
   - إمكانية تفعيل بروتوكول SSL/TLS بنقرة واحدة.
   - يقوم النظام بتوليد شهادة تشفير ذاتية التوقيع (Self-Signed Certificate) محلياً باستخدام مكتبة `cryptography` لحماية كلمات المرور والبيانات من التنصت على الشبكات العامة.
3. **مكافحة الهجمات وحماية المسارات (Path Traversal Protection):**
   - تنقية كافة أسماء الملفات عبر `werkzeug.utils.secure_filename`.
   - منع الوصول إلى المجلدات الحساسة الخاصة بالنظام مثل `C:\Windows` أو `C:\Program Files` لمنع التعديل أو الحذف غير المصرح به.
4. **حماية التكرار والنسخة الواحدة (Single Instance Lock):**
   - منع تشغيل أكثر من نسخة واحدة من التطبيق في نفس الوقت لمنع تعارض المنافذ أو ازدواجية الخوادم.
