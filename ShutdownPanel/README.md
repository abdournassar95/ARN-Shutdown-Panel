## 🌟 الميزات

### ⚡ التحكم بالطاقة
- تنفيذ أوامر النظام الحقيقية: إيقاف التشغيل، إعادة التشغيل، النوم، الإسبات، قفل الشاشة، تسجيل الخروج.
- **محرك عدّاد تنازلي دقيق** (Monotonic Deadline) بخيط مستقل مع إيقاف مؤقت/استئناف/إلغاء وتنبيهات صوتية ومنبثقة.
- **جدولة أسبوعية**: نفّذ إجراءً تلقائيًا في أوقات محددة (مثل: إيقاف التشغيل يوميًا 23:00).
- إيقاف/إسبات أجهزة أخرى على الشبكة عبر `shutdown /m`.

### 📱 التحكم عن بعد (LAN Remote)
- واجهة جوال كاملة **بالعربية والإنجليزية** تعمل من المتصفح — قابلة للتثبيت كتطبيق (PWA).
- **مصادقة برمز Token + رمز QR** للاتصال الفوري، مع تدوير الرمز وحد معدل الطلبات.
- **بث شاشة مباشر (MJPEG)** مع لمس الشاشة للنقر، ولقطات فورية.
- **تراك باد + لوحة مفاتيح** افتراضية بدعم كامل للعربية والاختصارات (Ctrl+C، Alt+Tab، Win+D…).
- **مدير ملفات كامل**: تصفّح الأقراص، رفع (بثّي مع حد حجم)، تنزيل، ضغط ZIP، إعادة تسمية، **حذف آمن إلى سلة المحذوفات**.
- **مدير عمليات**: استعرض الأكثر استهلاكًا وأنهِ أي عملية.
- **Wake-on-LAN** لإيقاظ أجهزة أخرى، و**مزامنة حافظة** (ويندوز).
- تحكم بالوسائط والصوت (دقيق عبر COM API) والسطوع.
- **HTTPS اختياري** بشهادة ذاتية التوليد تلقائيًا.

### 🖥️ سطح المكتب
- واجهة عصرية: عربي (RTL) / إنجليزي (LTR)، سمة داكنة/فاتحة.
- ويدجت ساعة على حافة الشاشة مع حالة العدّاد الحيّة.
- مراقبة عتاد حية: CPU / RAM / قرص / حرارة / **بطارية** / زمن تشغيل.
- أيقونة System Tray مع إشعارات ويندوز، تشغيل مع النظام، وحماية من تكرار التشغيل.
- وعي كامل بـ DPI (شاشات 125% / 150%).

### 🔒 الأمان
- كل نقاط النهاية محمية بالرمز (حتى رمز QR) — بلا CORS مفتوح.
- حماية مسارات النظام من الحذف/الكتابة، أسماء ملفات مُنقّاة ضد اجتياز المسارات.
- تحقق من صحة كل المدخلات + حدود أحجام الرفع/الضغط.
- سجل دوّار في `%APPDATA%/ShutdownPanelPython/logs/app.log`.

## 🚀 التشغيل

### 1) تثبيت المتطلبات
```bash
pip install -r requirements.txt
# اختياري — لتفعيل HTTPS بخادم الجوال:
pip install cryptography
```

### 2) التشغيل
* **تشغيل لوحة التحكم الرئيسية والخادم:**
  ```bash
  python main.py
  ```
* **تشغيل عميل التحكم عن بعد (من كمبيوتر آخر على الشبكة):**
  ```bash
  python client_main.py
  ```

### 3) الاتصال من الجوال
1. افتح تبويب **التحكم عن بعد** وفعّل الخادم.
2. امسح **رمز QR** بكاميرا الجوال (أدخل الرمز يدويًا إن رغبت).
3. استمتع بالتحكم الكامل. 💡 ثبّت الصفحة على شاشتك الرئيسية (PWA).

> ⚠️ **ملاحظة أمنية:** هذا التطبيق يمنح تحكمًا كاملًا بجهازك لمن يملك الرمز. استخدمه على شبكات موثوقة، وفعّل HTTPS، وبدّل الرمز دوريًا. عند تفعيل HTTPS سيعرض متصفح الجوال تحذير شهادة (طبيعي لأن الشهادة ذاتية التوقيع) — تجاوزه بعد التأكد من العنوان.

## 📦 التجميع كملف تثبيت و `.exe`

بأمر واحد يتم بناء النسخة الكاملة وحزمة التثبيت:
```bash
python build_exe.py
```
المخرجات في مجلد `dist/`:
- `dist/ShutdownPanel_Setup_v2.0.0.exe`: **حزمة التثبيت الموحدة**، وتتيح للمستخدم أثناء التثبيت اختيار تثبيت:
  - اللوحة الرئيسية (Host Server)
  - عميل التحكم عن بعد (Remote Client)
  - أو كلاهما معاً، مع إنشاء الاختصارات تلقائياً.
- `dist/ShutdownPanel.exe`: اللوحة الرئيسية المحمولة (Standalone).
- `dist/ShutdownPanelClient.exe`: عميل التحكم المحمول (Standalone).

## 🛠️ استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| الشاشة السوداء عند الإقلاع | ✅ حُلّت في v2 (خطوط محلية + إظهار النافذة بعد التحميل). إن تكررت: حدّث WebView2 Runtime |
| منفذ الجوال محجوب | جدار حماية ويندوز يمنع بايثون — اسمح له من رسالة الحماية أو يدويًا |

| الحرارة لا تظهر | غير متاحة على كل العتاد (تعتمد على ACPI Thermal Zone) |
| لا يمكن إنهاء عملية | تحتاج صلاحيات مسؤول النظام لبعض عمليات النظام |
